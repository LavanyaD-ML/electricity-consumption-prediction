# ⚡ Electricity Consumption Prediction & Energy Usage Analysis

An end-to-end Machine Learning project for household electricity consumption analysis, regression modeling, time-series forecasting, and interactive visualization using Python and Streamlit.

## 📌 Project Overview

Electricity Consumption Prediction & Energy Usage Analysis is a Machine Learning project designed to analyze historical household electricity consumption and estimate future electricity usage.

The project uses historical power consumption measurements to explore usage patterns, develop predictive features, train regression models, compare model performance, and evaluate forecasting results.

An interactive Streamlit dashboard provides access to data analysis, model training, evaluation, error analysis, and electricity consumption predictions.

## 🎯 Project Objectives

- Analyze historical household electricity consumption.
- Identify hourly, daily, and monthly usage patterns.
- Perform data cleaning and preprocessing.
- Develop time-based and historical consumption features.
- Train and compare multiple regression models.
- Evaluate models using regression metrics.
- Analyze prediction errors and feature importance.
- Perform time-series forecasting and backtesting.
- Estimate next-hour electricity consumption.
- Present results through an interactive Streamlit dashboard.

## 📊 Evaluation Metrics

The project can use the following regression metrics, depending on the metrics implemented in the training and evaluation modules:

- **Mean Absolute Error (MAE):** Measures the average absolute difference between actual and predicted values.
- **Mean Squared Error (MSE):** Measures the average squared prediction error.
- **Root Mean Squared Error (RMSE):** Measures the square root of the average squared prediction error.
- **R² Score:** Indicates how well the model explains variation in the target variable.

Model performance should be interpreted using the actual evaluation results generated by the project.

**DOI:** https://doi.org/10.24432/C58K54

### Dataset Description

The dataset contains household electric power consumption measurements collected at one-minute intervals over approximately 47 months, from December 2006 to November 2010.

It contains approximately 2.07 million measurements and includes the following variables:

- Date
- Time
- Global Active Power
- Global Reactive Power
- Voltage
- Global Intensity
- Sub-metering 1
- Sub-metering 2
- Sub-metering 3

### Target Variable

`Global_active_power`

This variable represents household global active power consumption and is used as the prediction target.

### Data Preprocessing

The original dataset may require preprocessing before it can be used by the application.

Depending on the implemented pipeline, preprocessing can include:

- Parsing date and time columns.
- Handling missing values.
- Converting measurement columns to numeric types.

- Creating time-based features.
- Generating lag and rolling features.

The exact preprocessing steps depend on the implementation in the project source files.
